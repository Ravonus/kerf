# @weft-js/plugin-media

> **Not released yet.** This add-on is private and isn't on npm. An app made from a Weft checkout can use it: see
> [Using a Weft checkout](../../docs/getting-started.md).

The media.build@1 provider (sharp + SVGO: AVIF plus a compatible fallback, an SSIMULACRA2 quality search, width ladders, placeholders), the media.server@1 route provider, and M001–M018.
