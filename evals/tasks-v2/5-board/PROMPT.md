Add these to our task board. Keep the existing columns, sections and labels.

1. **Filter.** A text input labelled **Filter**. Only tasks whose title contains the text (case-insensitive) are shown,
   in both columns.
2. **Counts.** Each column heading shows how many tasks it is currently showing, like `Todo (2)` and `Done (0)`.
3. **Add.** A form with a text input labelled **New task** and an **Add** button that adds an unfinished task with
   that title. Ignore blank titles and clear the input after adding.
4. **Notes.** Each task gets a text input labelled `Note for {title}` (use `aria-label`) where people jot down a note
   about that task.
