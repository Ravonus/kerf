# W012 (error)

`derived(async …)`, or reads after `await` in `resource` (untracked).

**Fix:** Use `resource`; read before the `await`.

**Status in weft@0.1.0:** not reported by this weft yet.

Triggers it:

```tsx
import { derived } from '@weft-js/core'
export function A() { const d = derived(async () => 1); return <p>{d.value}</p> }
```

More: `weft docs async`.
