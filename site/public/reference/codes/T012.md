# T012 (error)

A test ends with @weft-js/core/browser listeners, intervals or subscribed values still open (checked by @weft-js/core/test after each test).

**Fix:** Unmount what the test created (dispose any `createRoot`), or fix the leak.

**Status in weft@0.1.1:** reported by @weft-js/core/test after each test.

A test that needs it on purpose keeps it with a reason: `// weft-allow T012: <why>` in the file header (whole file) or on the line above.

More: `weft docs browser`.
