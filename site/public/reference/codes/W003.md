# W003 (error)

`watch` writes state that its own source reads (cycle).

**Fix:** Use `derived`.

**Status in weft@0.1.0:** not reported by this weft yet.

Triggers it:

```tsx
import { state, watch } from '@weft-js/core'
export function A() { const a = state(0); watch(() => a.value, v => { a.value = v + 1 }); return <p>{a.value}</p> }
```
