# W004 (warning)

`watch` that only copies one value into another.

**Fix:** Replace with `derived`.

**Status in weft@0.1.0:** not reported by this weft yet.

Triggers it:

```tsx
import { state, watch } from '@weft-js/core'
export function A() { const a = state(0); const b = state(0); watch(() => a.value, v => { b.value = v }); return <p>{b.value}</p> }
```
