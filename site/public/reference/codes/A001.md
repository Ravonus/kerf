# A001 (error)

The auth secret is missing or under 32 characters on a production server.

**Fix:** Set `BETTER_AUTH_SECRET` (`openssl rand -base64 32`) in the server's environment.

**Status in weft@0.1.0:** reported by @weft-js/start when it serves or renders the route, and by weft check and `weft routes --meta`.

More: `weft docs start`.
