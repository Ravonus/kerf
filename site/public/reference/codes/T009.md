# T009 (error)

`.only` or `.skip` committed (also `fit`, `xit`, `xdescribe`).

**Fix:** Remove `.only`; fix or delete a skipped test (`test.fails` for one meant to fail).

**Status in weft@0.1.1:** reported by weft check on test files, safe autofix.

Triggers it:

```tsx
test.only('focused', () => { expect(Math.max(1, 2)).toBe(2) })
```

A test that needs it on purpose keeps it with a reason: `// weft-allow T009: <why>` in the file header (whole file) or on the line above.

More: `weft docs testing`.
