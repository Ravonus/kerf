# W014 (error)

Identity-breaking `.map(p => ({ ...p, … }))` feeding a keyed list: every row re-runs on every change (in-file, and across files via props in `weft check`).

**Fix:** Replace only the changed item (`p.id === id ? { ...p, price } : p`), or read the changing field live.

**Status in weft@0.1.1:** reported.

Triggers it:

```tsx
import { state } from '@weft-js/core'
export function A() { const xs = state([{ id: 'a', price: 1 }]); const push = (price: number) => { xs.value = xs.value.map(p => ({ ...p, price })) }; return <ul onClick={() => push(2)}>{xs.value.map(p => <li key={p.id}>{p.price}</li>)}</ul> }
```
