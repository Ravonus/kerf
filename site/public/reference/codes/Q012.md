# Q012 (error)

`@weft-js/start/db*` or `@weft-js/start/auth` reached the client graph.

**Fix:** Import it from a server module (`src/server/**`, `*.server.ts`) or a route's `load`.

**Status in weft@0.1.1:** reported by @weft-js/start when it serves or renders the route, and by weft check and `weft routes --meta`.
