# W054 (error)

`media(query)` without `ssr` in a server-rendered component (hydration mismatch); a warning when `weft check` cannot tell.

**Fix:** Pass the server value: `media(query, { ssr: false })`.

**Status in weft@0.1.1:** reported, suggested edit.

Triggers it:

```tsx
import { media } from '@weft-js/core/browser'
export function A() { const dark = media('(prefers-color-scheme: dark)'); return <p>{dark.value ? 'dark' : 'light'}</p> }
```

More: `weft docs browser`.
