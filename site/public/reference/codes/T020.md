# T020 (error)

An existing test deleted, skipped, marked `.fails`, or with an assertion removed or loosened (`toBe(3)` → `toBeTruthy()`).

**Fix:** Restore it, or keep the change with `// weft-allow T020: <reason>` on that test.

**Status in weft@0.1.1:** reported by `weft test --gate` on a diff.

A test that needs it on purpose keeps it with a reason: `// weft-allow T020: <why>` in the file header (whole file) or on the line above.

More: `weft docs verify`.
