# W052 (error)

`watch` folding a stream by hand.

**Fix:** `fold` + `initial` where it is read: kept in the cache.

**Status in weft@0.1.0:** reported.

Triggers it:

```tsx
import { state, watch } from '@weft-js/core'
import { prices } from './server/prices'
export function A() { const tick = prices({}); const list = state([]); watch(() => tick.value, m => { list.value = [...list.value, m] }); return <p>{list.value.length}</p> }
```
