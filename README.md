# weft

A fine-grained reactive UI system built for how coding agents reason. Plain TSX, components run once, state is
an equation (`derived`), and every way to get it wrong is a compile error with a code and a fix.

Includes a T3-style full stack (Zod + TypeScript, server functions, tagged caching), first-class canvas/WebGL
surfaces (Keel engine), and an agent-driven design language that coexists with Tailwind or any CSS.
