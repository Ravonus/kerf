# OG renderer spike (research 20 §7.3)

Throwaway code that picks the OG card rasterizer for [research 20](../../docs/research/20-metadata-and-og.md): Takumi
(`@takumi-rs/core` native, `@takumi-rs/wasm`) against Satori + resvg (`resvg-js` native, `resvg-wasm`). The results
and the recommendation are in research 20 §9. This folder has its own `package.json`, so none of it reaches the weft
package's dependencies.

```
cards/*.tsx          the cards, as ordinary weft TSX: Default (title, description, site), Avatar (image, two fonts,
                     radius, border, shadow), Stress (CSS outside the flex subset; quality only, not timed)
build-cards.mjs      weft's native compiler (`generate: 'ssr'`, not hydratable) + weft/ssr → build/cards.mjs, one ES
                     module that runs on Node, Bun and workerd
renderers.mjs        the two pipelines behind `renderCard(html, size, fonts) → PNG`, given each runtime's modules
html-to-vnode.mjs    weft HTML → Satori's element shape (satori-html crashes on Bun and drops inline whitespace)
bench.mjs            one cold process of one pipeline on Node or Bun; `--save` writes out/*.png
worker/              the wasm pipelines as Workers; client.mjs times them through `wrangler dev` (workerd, local)
run-all.mjs          every measurement → results/results.json
card/                renderCard: Takumi plus Satori's strengths (strict styles → M005, any font format, preview page,
                     Response helper) and §4.1's image fetching (→ M008). index.mjs, native.mjs / wasm.mjs, tests,
                     bench.mjs, preview.mjs; research 20 §9.8
out/                 sample PNGs (each card from Takumi native and Satori + resvg-js; the other pipelines' PNGs are
                     regenerated by `--save`) and the HTML each card rendered to
```

## Run

```bash
cd spikes/og && npm install
node ../../packages/weft/scripts/build-native.mjs   # weft's compiler, if packages/weft/native is empty
node build-cards.mjs
node run-all.mjs 5 100                              # 5 cold samples, 100 warm renders per card (~3 min)
npm test                                            # renderCard's tests
node card/bench.mjs && node worker/client.mjs card  # renderCard's cost, on Node and in workerd
npx wrangler deploy --dry-run --outdir build/worker-takumi -c worker/wrangler.takumi.jsonc   # Worker size
```

Nothing here deploys or signs in anywhere: `wrangler dev` runs workerd locally, and `--dry-run` only bundles.

## Versions

Pinned to releases at least two weeks old on 2026-10-29: Takumi 2.16.2, satori 0.57.2 (Node, Bun) and 0.32.0
(workerd, as `satori-032`; see `worker/satori.mjs` for why), resvg 2.6.2, wrangler 4.150.0, @fontsource Inter and Lora
5.3.0. `@vercel/og` 1.0.3 is installed only to measure its size: its Node build throws `Dynamic require of "fs"` under
plain Node ESM.
