Time, place
& ink.

Dates, ranges, time, phone numbers, rich text, signatures, filters and ordering, all in one field shell: label, a 3:1 control boundary, hint or error. The value is always a plain ISO string an agent can read. Every day cell has a full name. On phones they become sheets, and they follow the dial from quiet to vivid.

02Motion

Four moments at each stop of the dial

Month slide, popover, sheet and validation, each using the components' own CSS. Quiet cross-fades with 4px of travel. Balanced slides 16px. Vivid slides 24px with a leading-edge wipe, a spring on scale and a validation edge that sweeps in. With reduced motion every one becomes a fade with no travel. No stop shakes a field.

03On phones

Native or a custom sheet, decided per input

Use native when the OS control is strictly better and the value fits it. Use a custom sheet when the input needs something native can't do: ranges, presets, unavailable dates, the app's locale rather than the device's, or search.

InputPhone presentationWhy
DateBottom sheet, month grid + typed boxNative can't show unavailable days or presets, and it takes the device locale rather than the app's.
Date rangeFull-height sheet, chips + one monthTwo months can't fit 390px; native has no ranges.
