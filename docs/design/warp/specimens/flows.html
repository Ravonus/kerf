Flows.

The screens every product ships before its first real feature: getting in, getting set up, changing settings, paying, and recovering when something breaks. Each flow is one Zod schema bound to one mutation, laid out three ways, and signed with the sweep only where it earns its place: fields, progress the user caused, the one primary action, and the moment something is accepted.
