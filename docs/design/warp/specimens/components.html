§0Signature

The sweep

Two stacked 1px borders: a resting base and an accent sweep. In, the sweep draws left to right while the base wipes away under it. Out, the sweep keeps travelling right; it never reverses. The phase machine is idle → in → out → idle, one attribute per change, reset on transitionend. Errors pin it in, in critical. Under reduced motion it is an instant colour change.

§1Actions

Buttons and their kin

One solid per region; everything else is soft, outline, ghost, frame or link. Tone changes meaning, not emphasis. Icon-only buttons must have a name (a type error without one) and get a 44px hit area on touch even when the glyph is 14px.

§2Overlays

Layers that behave

Native <dialog> for anything modal (top layer, inert page, focus return). Popovers in the top layer for anything anchored. One dismiss stack: Escape and an outside press close only the top layer, so a select inside a dialog closes first. Scroll locks only for modals, with the gutter reserved so nothing jumps.

    §5Feedback

    Saying what happened

    Toasts for things that just happened, alerts for things that are true now, banners for the whole page, callouts for prose. Prefer undo to confirm. Live regions are mounted once at load, so every message is actually announced: polite by default, assertive only for failures.

    Toast

    stack · swipe · pause

    Up to three show; the rest wait. Hover or focus fans the stack out and pauses the timer (the hairline at the bottom). Swipe sideways to dismiss. F8 jumps to the region.

    weft
    toast({ tone: "positive", title: "Saved" })
toast({ tone: "critical", title: "Sync failed",
        action: { label: "Retry", onPress: retry } }) // assertive, persists
toast.promise(upload(), { pending: "Uploading…", done: "Uploaded" })
